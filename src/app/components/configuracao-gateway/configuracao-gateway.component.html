Remover configuração de gateway

Remover a configuração de gateway do tenant {{ itemParaRemover.tenantId }} ({{ itemParaRemover.company }})?

Só a configuração de gateway é removida — os demais dados do tenant no srv-catra (ex: Firebase) são preservados. Os pagamentos desse tenant param de funcionar até uma nova configuração ser criada.
Excluir tenant definitivamente

Excluir o tenant {{ itemParaExcluir.tenantId }} ({{ itemParaExcluir.company }}) do srv-catra?

Irreversível. Apaga o registro inteiro do tenant no DynamoDB: apiKey, configuração de gateway, credencial Firebase e reCAPTCHA. O tenant deixa de autenticar no srv-catra imediatamente.
Não são apagados: os arquivos do tenant no S3, a autorização do vendedor no lado do Mercado Pago e os registros deste painel (Configuração de Tenants/Environments — remova nas respectivas telas).
